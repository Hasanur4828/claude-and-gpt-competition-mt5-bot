# P2 — দৈনিক লস গণনায় server time (GPT ২-খ)

> **প্রস্তাব — চালু নয়।** চালু প্যাকেজের ফাইল বদলানো হয়নি। লিখিত অনুমোদন ছাড়া প্রতিযোগিতায় ব্যবহার করা যাবে না।
> সব পরীক্ষা নকল broker-এ চালানো হয়েছে; আসল MT5-এ একটাও নয়।

* ফাইল: `gpt_liquidity_fibonacci_scalper_v1.py` · SHA-256 `3556dd076812f5293d5b127ccecf5686dda6e7f692af0b07c4a2df6f285efd17`
* বদলের জায়গা: `_daily_loss_count()` + নতুন `_server_offset_seconds()`
* diff: `diff_vs_v1_0.diff`

MT5-এর deal time broker server time-এ থাকে, অথচ v1.0 query করে UTC-র আজকের ০০:০০ থেকে এখন পর্যন্ত।
broker UTC+3 হলে শেষ ৩ ঘণ্টার লস বাদ পড়ে, ফলে দৈনিক ২-লস সীমা দেরিতে কাজ করে।
P2 যা করে:
* query-র সময়-জানালা চওড়া করা হয়েছে।
* সবচেয়ে তাজা tick থেকে server offset অনুমান করা হয় (আধা ঘণ্টায় round করা; tick-এর বয়স ≤ ৫ মিনিট হতে হবে; সীমা ±১৪ ঘণ্টা)।
* "আজ" ধরা হয় UTC-র আজকের মধ্যরাত + offset থেকে।
* offset জানা না গেলে রক্ষণশীল নিয়ম চলে: গতকালের শেষ দিকের লসও গোনা হতে পারে, ফলে GPT আগে থামে, কখনো দেরিতে নয়।
